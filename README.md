# Rick and Morty UI

Projeto desenvolvido com o objetivo de consumir e exibir dados da **API do Rick and Morty**, utilizando **Qt (C++ + QML)** em live coding.

---

##  Live Coding

Este projeto foi desenvolvido durante uma sessão de **live-coding**.

- A branch **`live-coding`** contém **exatamente o código produzido durante a live**, incluindo:
    - decisões tomadas em tempo real
    - código incremental
    - eventuais ajustes e experimentações feitas ao longo do desenvolvimento

---

## Versão Final

A branch **`master`** contém a **versão final e consolidada do projeto**, com:
- organização de código
- ajustes arquiteturais
- correções e melhorias aplicadas após a live
- estrutura pronta para estudo, manutenção e evolução

---

## Branches

- **`live-coding`** → código produzido durante o live-coding
- **`master`** → versão final e refinada do projeto

---

## Objetivo

O projeto tem como objetivo:
- explorar o consumo de APIs REST em C++
- integrar backend C++ com frontend QML
